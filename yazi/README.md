# Конфигурация Yazi

Минимальная конфигурация терминального файлового менеджера Yazi с отображением скрытых файлов и привычными клавишами файловых операций.

## Файлы

| Файл | Что делает |
| --- | --- |
| `yazi.toml` | Включает показ скрытых файлов |
| `keymap.toml` | Добавляет пользовательские клавиши поверх стандартной раскладки |

## Зависимости

```bash
sudo pacman -S --needed yazi fd
```

`fd` используется поиском по клавише `s`. Для полноценного preview разных форматов Yazi может предлагать дополнительные необязательные пакеты — их список виден в `yazi --debug`.

## Установка

```bash
mkdir -p ~/.config/yazi
cp -a ./yazi/. ~/.config/yazi/
```

## Клавиши

| Клавиша | Действие |
| --- | --- |
| `c` | Копировать выбранное |
| `x` | Вырезать выбранное |
| `v` | Вставить |
| `r` или `Delete` | Переименовать; курсор перед расширением |
| `s` | Поиск через `fd` |
| `t` | Новая вкладка в текущем каталоге |
| `Ctrl+t` | Закрыть текущую вкладку |

Пользовательские правила находятся в `prepend_keymap`, поэтому имеют приоритет над встроенными клавишами Yazi.

## Проверка

```bash
yazi --debug
```

Для диагностики TOML также можно временно запустить Yazi с отдельным каталогом через переменную `YAZI_CONFIG_HOME`.
