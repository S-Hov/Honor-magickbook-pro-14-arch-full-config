# Zed

config/ устанавливается в ~/.config/zed, codebook/ — в ~/.config/codebook.
Тема VSCode Dark Modern, Material Icon Theme, базовые клавиши VS Code.
Alt+Shift+Up/Down дублируют строку, Ctrl+Alt+T открывает Kitty в проекте.
Ctrl+Shift+G открывает Git Panel; Ctrl+Alt+G — Git Graph.
Локальный ИИ отключён. Модели, переводчик и ИИ-коммиты не устанавливаются.
Редактор в Arch запускается командой zeditor (в Fish есть alias zed).
Установка — через корневые install.sh / restore.sh.
