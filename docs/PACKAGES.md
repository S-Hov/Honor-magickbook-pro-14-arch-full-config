# Программы

`packages/official.txt` и `packages/aur.txt` — списки, используемые установщиком.
Noctalia v5 берётся из официального репозитория, Brave/cliamp/Shelly — из AUR.
Не все пакеты из прежней системы нужны новой: Lenovo cooling, NVIDIA-инструменты
и локальные модели Ollama исключены.

`packages/installed-explicit.txt` и `packages/installed-foreign.txt` — справочный
снимок текущей системы. Установщик их не выполняет: там могут быть приложения
из дополнительных репозиториев и AUR, требующие отдельной установки.

Профили VPN, настройки подключений и входы в аккаунты не входят в набор.
Docker и Antigravity встречаются в личных Fish alias, но не устанавливаются
автоматически. Их можно установить отдельно, если они нужны.

В Zed сохранены auto_install_extensions: темы/иконки, Biome, Codebook, Emmet,
HTML, SCSS, Prisma и Dockerfile. Zed скачает расширения при первом запуске.
Модели и интеграции Ollama отключены. Для запуска редактора в Arch используется
`zeditor`; в Fish предусмотрен alias `zed`.

## Zed: типы, наведение и переход к определению

JavaScript, JSX, TypeScript и TSX используют встроенный в Zed сервер `vtsls`.
Включённый hover в глобальных настройках не поможет, если в проектном
`.zed/settings.json` стоят одновременно `!vtsls` и `!typescript-language-server`.
Символ `!` отключает сервер. Для обычного TS/JS-проекта можно использовать:

```json
"language_servers": ["vtsls", "codebook", "!biome", "!typescript-language-server", "..."]
```

Это пример для проекта, в котором Biome намеренно отключён; отключать его
во всех проектах не требуется. Старый `ollama-hover-translate` не нужен для
подсказок типов и в эту сборку не входит. Настройки из `.zed/` проекта могут
переопределять пользовательский конфиг. После исправления дайте серверу
завершить индексацию; при необходимости выполните в палитре команд
`editor: restart language server`. Переход к определению: Ctrl+Click или F12.

26 октября 2026 такое отключение исправлено в проекте Auto-admin. Проверены
реальные LSP-запросы: hover возвращает `Map<number, StoredField>`, definition
находит определение импортированной функции в другом файле.

Постоянные серые вставки типов и имён параметров скрыты: `inlay_hints.enabled = false`.
Подсказки типов при наведении, автодополнение и Ctrl+Click остаются включены.

## Zed: импорты типов и неиспользуемые переменные

В пользовательском конфиге включено
`lsp.vtsls.settings.typescript.preferences.preferTypeOnlyAutoImports = true`.
При выборе типа из автодополнения TypeScript 5.3+ предпочитает `import type`.
Уже написанные импорты эта настройка сама по себе не переписывает.

Подчёркивание задаётся также настройками конкретного проекта:

- Для ESM-проектов: `verbatimModuleSyntax: true` требует `type` для импортов
  интерфейсов и псевдонимов типов; `noUnusedLocals: true` проверяет
  неиспользуемые локальные переменные и импорты.
- Для CommonJS с ES-синтаксисом импортов не включайте `verbatimModuleSyntax`
  без перехода проекта на ESM. Используйте ESLint с правилами
  `@typescript-eslint/consistent-type-imports` и `@typescript-eslint/no-unused-vars`.
  Зависимости и конфигурация ESLint должны находиться в самом проекте.

В сервере Auto-admin добавлен `eslint.config.mjs` с этими двумя правилами
на уровне предупреждений и команда `npm run lint`. Имена с префиксом `_`
разрешены как намеренно неиспользуемые. Во фронтенде проверки TypeScript
и ESLint уже были включены. Глобальный `source.fixAll.eslint` выполняет
доступные исправления ESLint при сохранении, в том числе добавление `type`.
Настройки проекта Auto-admin не входят в этот переносимый набор конфигов.
Если после установки ESLint предупреждения не появились, выполните
`editor: restart language server` в палитре команд Zed.
