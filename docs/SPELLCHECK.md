# Проверка правописания: русский и английский

## Системные приложения

Установлены `hunspell`, `hunspell-ru`, `hunspell-en_us`. Словари находятся в
`/usr/share/hunspell/`. Они обеспечивают проверку в приложениях, использующих
Hunspell/Enchant; единого переключателя для всех приложений Linux нет.

Проверка словаря:

```bash
printf 'привет\nпревет\n' | hunspell -d ru_RU -l
```

В выводе должна остаться только опечатка «превет».

## Telegram Desktop

У Telegram есть собственный выбор языков и папка словарей.
При подготовке настройки русский `.aff`/`.dic` копируется из системного
пакета в `~/.local/share/TelegramDesktop/tdata/dictionaries/ru_RU/`.

Перезапустите Telegram. В Настройках → Продвинутые настройки найдите блок
проверки правописания (Spell checker), включите проверку и в управлении
словарями выберите русский вместе с английским. В некоторых версиях выбор
доступен из контекстного меню поля ввода → Spelling / Правописание.
Настройки аккаунтов Telegram зашифрованы; скрипт их не изменяет.

## Приложение ChatGPT (Electron)

В профилях был выбран только `en-US`. Установлен пользовательский запускатель
`~/.local/bin/chatgpt`: перед запуском системного `/usr/bin/chatgpt` он включает
языки проверки `en-US` и `ru` в существующих Preferences, сохраняя остальные
настройки, включая язык интерфейса. Локальный desktop-файл использует этот
запускатель. Системные файлы приложения не изменяются.

Полностью закройте приложение и снова откройте через меню приложений.
Перезагрузка компьютера не нужна. Во время работы Electron может перезаписывать
Preferences, поэтому применять языки нужно именно перед запуском.

Русский Chromium-словарь `ru-RU-3-0.bdic` хранится в
`~/.local/share/honor-spellcheck/` и `~/.config/Codex/Dictionaries/`.
При первом запуске скачивается из официального репозитория Chromium,
проверяется по SHA-256. Проверка выполняется локально; онлайн-сервис проверки
орфографии отключён. Личные Preferences и словари пользовательских слов
в этот репозиторий не копируются.

Подготовка без запуска приложения:

```bash
~/.local/bin/chatgpt --honor-prepare-spellcheck
```

При восстановлении на другом имени пользователя пути подставляются автоматически.
Для отмены удалите локальный `~/.local/bin/chatgpt` и локальный
`~/.local/share/applications/chatgpt.desktop`: останется системный запускатель.

Проверка после перезапуска: введите «привет превет проверка праверка» в поле
сообщения, ничего не отправляя. Опечатки должны подчёркиваться. Встроенная
проверка орфографии не заменяет проверку грамматики и пунктуации.

Источники: [Electron SpellChecker](https://www.electronjs.org/docs/latest/tutorial/spellchecker),
[словари Chromium](https://chromium.googlesource.com/chromium/deps/hunspell_dictionaries/),
[Telegram Desktop](https://github.com/telegramdesktop/tdesktop).
