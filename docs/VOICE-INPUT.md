# Голосовой ввод на русском через Intel NPU

## Как пользоваться

Поставьте курсор в нужное поле. Нажмите **Super+Ctrl+R**, произнесите текст,
затем нажмите сочетание ещё раз. Запись завершится, Whisper распознает русский
текст локально на NPU, скопирует результат в буфер и вставит его в активное поле.
**Enter не нажимается: сообщения и команды автоматически не отправляются.**

**Super+Ctrl+Esc** отменяет запись или ожидаемую вставку. Максимум одной записи —
120 секунд; затем распознавание начинается автоматически.

Используется текущий микрофон, выбранный в системе, в том числе Galaxy Buds.
Если микрофон выключен, диктовка попросит включить его; сама mute не снимает.
Громкость и выбор устройства настраиваются в Noctalia. Если выбранный
Bluetooth-микрофон требует режима гарнитуры, он временно включается на запись;
после остановки возвращается предыдущий профиль (например A2DP). На время
записи качество воспроизведения в Bluetooth-наушниках может измениться. Если активное окно
сменилось за время записи/распознавания, текст остаётся только в буфере обмена.
Вставьте его вручную. Результат также можно вставить повторно из буфера.

Для вставки создаётся виртуальная клавиатура через `/dev/uinput`.
Она отправляет Ctrl+V в обычные поля, а для распространённых терминалов —
Ctrl+Shift+V. В приложениях с другими привязками вставьте текст вручную.
Записывайте при установленном курсоре в поле и не меняйте его во время ожидания.

## Установка на восстановленной системе

```bash
./install-voice-input.sh
```

Скрипт устанавливает пакеты Arch, добавляет пользователя в `render`, создаёт
изолированное Python-окружение и загружает конвертированную модель
`OpenVINO/whisper-small-int8-ov` (~240 MiB весов). Ревизия закреплена в
`voice-input/model.json`; LFS-веса проверяются по SHA-256. Модели, окружение и
компиляционный кэш в GitHub не включаются. Основной `install.sh` не загружает
модель автоматически: голосовой ввод устанавливается отдельной командой.

Привязки Niri входят в конфиг этой сборки. Их восстановление выполняет `restore.sh`.
Служба запускается сочетанием клавиш по требованию и держит загруженную модель
до завершения сессии или ручной остановки. На первой загрузке компиляция на этом
Honor заняла около 36 секунд; после кэширования загрузка заметно быстрее.
Модель и кэш занимают место на диске, загруженная модель — оперативную память.

## NPU и доступ

При проверке 24 октября 2026 NPU определялся ядром, но после установки драйвера
`/dev/accel/accel0` имел права 0660 root:render, а пользователь не входил в render.
Из-за этого OpenVINO выводил только `['CPU']`. После выдачи доступа:

```text
['CPU', 'NPU']
Intel(R) AI Boost
```

Скрипт добавляет пользователя в группу render для следующих входов и выдаёт
индивидуальный ACL на существующий accel0 для текущего входа. Для автоматической
вставки также загружается `uinput`, устанавливается правило uaccess для активной
локальной сессии и выдаётся индивидуальный ACL на `/dev/uinput` на текущий вход.
Доступ к чтению физических клавиатур не выдаётся. Доступ всем
пользователям не открывается. При замене устройства/сбросе ACL до нового входа
может понадобиться выйти из сессии и войти снова.

WhisperPipeline создаётся с устройством `NPU`. На CPU автоматически не
переключается: если NPU недоступен, выводится ошибка. Подготовка аудио и текста
всё равно использует CPU — ускоряются вычисления нейросети.

## Диагностика

```bash
honor-dictation status
journalctl --user -u honor-dictation.service -b
systemctl --user restart honor-dictation.service
systemctl --user stop honor-dictation.service
python -c 'import openvino as ov; print(ov.Core().available_devices)'
```

Файлы:

- `~/.local/share/honor-dictation/` — модель, окружение, программа;
- `~/.cache/honor-dictation/` — скомпилированные модели;
- `~/.config/systemd/user/honor-dictation.service` — служба;
- `$XDG_RUNTIME_DIR/honor-dictation/` — закрытый IPC-сокет и временная запись.

Аудио удаляется после распознавания, отмены или ошибки. Распознанный текст
остаётся в буфере обмена и может сохраняться менеджером буфера Noctalia.
В журнал пишутся длительность обработки и число символов, а не диктуемый текст.
Интернет нужен для установки и загрузки модели; распознавание работает локально.

Источники: [OpenVINO GenAI: NPU и Whisper](https://docs.openvino.ai/2026/openvino-workflow-generative/inference-with-genai/inference-with-genai-on-npu.html),
[модель OpenVINO](https://huggingface.co/OpenVINO/whisper-small-int8-ov).

## Результаты проверки

На встроенном микрофоне захвачена реальная речь; Whisper на NPU распознавал
пробные фразы за 0,2–0,4 секунды. Полная автоматическая проверка
«эталонное аудио → NPU → буфер → настоящее поле GTK» прошла: 107 символов
вставлены однократно, без Enter. `wtype` заменён на uinput. Учтено, что
`wl-copy` запускает постоянный процесс-владелец: его выходные потоки не
захватываются, чтобы не блокировать вставку до тайм-аута.

NPU обнаружен и модель успешно загружена. На эталонном фрагменте JFK из
официального whisper.cpp (~11 секунд) NPU распознал речь примерно за 0,4 секунды
после загрузки модели. Это отдельный тест вычислений; результат реальной
диктовки зависит также от выбранного микрофона и качества записи.


## Полное отключение

```bash
systemctl --user stop honor-dictation.service
```

Удалите две привязки `Mod+Ctrl+R` и `Mod+Ctrl+Escape` из Niri. При полном удалении
диктовки можно также удалить созданные ею `/etc/udev/rules.d/70-honor-dictation-uinput.rules`
и `/etc/modules-load.d/honor-dictation.conf`, затем перезагрузиться. Не удаляйте
доступ render, если NPU/GPU используется другими программами.
