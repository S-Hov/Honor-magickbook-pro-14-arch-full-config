# Отпечаток пальца: EgisTec 1c7a:05aa

Для встроенного в кнопку питания сканера EgisTec ETU906Axx (`1c7a:05aa`).
Проверяйте USB ID через `lsusb`: для других сканеров эта сборка не подходит.

Стандартный libfprint 1.94.100-1 в Arch этот ID не распознаёт. Опциональный
пакет `honor-fmbp-libfprint-sdcp` собирается из ветки libfprint SDCP v2 с
патчами устройства. Установленный стандартный libfprint сохраняется;
дополнительная библиотека выбирается через ld.so.conf.d.

## Проверено на этом Honor

18 октября 2026: драйвер собран и установлен, устройство обнаружено fprintd.
Отпечаток записан (`enroll-completed`), отдельная проверка вернула `verify-match`.
Пользователь подтвердил разблокировку экрана Noctalia без ввода пароля.
Вход SDDM оставлен парольным. Для sudo добавлен отдельный скрипт настройки ниже; реальная проверка `sudo -k -v`
успешно завершилась по отпечатку без ввода пароля.
Поведение после сна и перезагрузки отдельно пока не проверялось.

## Установка

```bash
./install-fingerprint.sh
fprintd-enroll -f right-index-finger
fprintd-verify
```

Сборка выполняется обычным пользователем, установка пакетов — через sudo.
Нужно примерно 15 касаний поверхности кнопки питания. Убирайте палец между
касаниями и немного меняйте положение; нажимать кнопку не нужно. Если ничего
не прикладывать, запись завершается по тайм-ауту — команду можно повторить.

Исходный рецепт, патчи и лицензия находятся в `hardware/fingerprint/`.
Ревизии исходников зафиксированы в `source.json` и PKGBUILD; готовые бинарные
пакеты и личные отпечатки в репозиторий не включены.

## Noctalia

Noctalia 5.3 использует fprintd напрямую и умеет проверять отпечаток параллельно
с вводом пароля. В `[lockscreen]` должно быть `fingerprint = true` (это значение
по умолчанию). Заблокируйте экран через `Super+Alt+L` и приложите записанный палец.
Пароль остаётся доступен. Не добавляйте pam_fprintd в глобальные `system-auth`
или `login` для Noctalia: параллельные клиенты могут мешать друг другу.

## Sudo в терминале

После успешной записи и проверки отпечатка:

```bash
sudo ./enable-sudo-fingerprint.sh
```

Скрипт сохраняет резервную копию `/etc/pam.d/sudo` в `/var/backups/honor-sudo-fingerprint-*`
и добавляет перед существующей авторизацией:

```pam
auth        sufficient    pam_fprintd.so max-tries=1 timeout=10
```

При запросе sudo приложите любой записанный палец. Если совпадения нет или
прошло 10 секунд, появится обычный запрос пароля. PAM проверяет методы
последовательно: ввод пароля во время ожидания отпечатка не обрабатывается.

Для проверки с обязательным новым запросом авторизации:

```bash
sudo -k -v
```

После успешной авторизации sudo обычно несколько минут не спрашивает ни пароль,
ни отпечаток — действует стандартный кэш sudo.
Для возврата сохраните остальные настройки и удалите добавленную строку либо
восстановите файл `sudo` из своей резервной копии.

Автоматическая установка драйвера и основной `install.sh` не включают этот режим.
Он включается отдельным скриптом по желанию пользователя. Отпечаток в sudo позволяет
подтверждать привилегии одним касанием; прикладывайте палец только к ожидаемому
запросу sudo (см. [предупреждение ArchWiki](https://wiki.archlinux.org/title/Fprint#Login_configuration)
об использовании биометрии для повышения привилегий).

Экран входа SDDM и общие PAM-файлы `system-auth`/`login` этот скрипт не меняет.
Noctalia работает с fprintd напрямую.

## Windows при двойной загрузке

Автор драйвера обнаружил, что Windows может удалить Linux-отпечатки из памяти
этого сканера уже при загрузке экрана входа. Если после Windows отпечаток
исчез, проверьте `fprintd-list "$USER"` и запишите его повторно.
Предлагаемый автором вариант — отключить сканер в диспетчере устройств Windows;
тогда Windows Hello по отпечатку перестанет работать. Windows скрипт не меняет.

## Диагностика и удаление

```bash
lsusb -d 1c7a:05aa
fprintd-list "$USER"
ldd /usr/lib/fprintd | rg libfprint
journalctl -u fprintd -b
sudo pacman -R honor-fmbp-libfprint-sdcp
```

После удаления дополнительного пакета снова используется стандартный libfprint.
Удаление драйвера не убирает отдельную PAM-настройку sudo: без сканера она
переходит к паролю. При полном отказе от отпечатков удалите строку pam_fprintd из `/etc/pam.d/sudo`.

Источники: [драйвер и отчёт автора](https://github.com/drphilth/honor-fmbp-libfprint-sdcp),
[настройки Noctalia](https://github.com/noctalia-dev/noctalia/blob/main/docs/user/configuration/shell.mdx).
